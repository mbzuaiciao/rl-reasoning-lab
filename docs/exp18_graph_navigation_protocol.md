# EXP-018 · Frozen graph-navigation protocol

[Issue #23](https://github.com/mbzuaiciao/rl-reasoning-lab/issues/23) · [Episodes](../experiments/exp18/episodes.json)

Freeze ten hand-designed directed topologies with branches, cycles, and shortest paths of three to six moves. Graph seeds 18001–18010 drive the relabeling and shuffling of adjacency rows and neighbor order. The committed JSON is authoritative. Its SHA-256 is `18ce5ddba522e5cfe40b41f7b78f21c5e96a908d0509cb1954dc99b0799d08b4`. Each episode uses its stored start, goal, and budget of five or six attempts in both arms.

Each independent model call receives the directed graph, goal, current node, legal neighbors, and remaining attempts. After turn one, the feedback arm adds a single line giving the direction of the previous attempt's distance change (decreased, stayed the same, or increased). Both arms see only the current observation and share the exact first-turn prompt. The environment strips surrounding whitespace, then accepts exactly one uppercase ASCII letter if it names a legal neighbor. Any other output consumes an attempt and leaves the node and distance unchanged. Stop at the goal or when attempts run out.

Use the already cached Qwen3.5-4B UD-Q4_K_XL GGUF and llama.cpp build `2a66703` from [EXP-014](exp14_model_selection_report.md). Verify the pinned weights and backend. Run offline on four CPU threads, with no GPU offload, a 1,024-token context, direct answers, no prompt caching, temperature 0.8 followed by top-p 0.95, no top-k cutoff, and eight new tokens per action. Use the checkpoint's chat template and the [frozen prompt](../experiments/exp18_graph_navigation.py). Run episodes in fixture order and alternate which arm runs first, starting with state-only. For one-based episode and turn numbers, use seed `180000 + 10 × episode + turn` in both arms. Attempt each slot once.

Before the pilot, run a shortest-path oracle and a fixed-first-neighbor baseline on every graph. Check feedback on every nonterminal legal edge and an invalid action from each nonterminal node against independent forward shortest-path calculations. Check that adding feedback only appends the specified line. Verify the local runtime with an unrelated one-letter smoke decode. Start the 600-second wall timer after preflight. Retain all available turns and compare only complete pairs.

Report success, steps taken, steps to goal among successes, invalid attempts, and paired outcomes. An episode is helpful if only feedback solves it, harmful if only state-only solves it, and tied otherwise. Report step differences separately for pairs both arms solve. Go requires at least eight complete pairs, at least three feedback-only successes, and at most one state-only success. This is a descriptive directional criterion.
